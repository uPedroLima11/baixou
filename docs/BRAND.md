# Marca Baixou!
Logo raster criada com a ferramenta Imagegen integrada (sem chave API nem execução paga adicionada ao projeto).
Arquivo consumido pelo app: public/logo.png. Fundo transparente, ícone laranja e palavra branca para cabeçalho carvão.
Prompt: logo-brand; logo original horizontal para catálogo brasileiro Baixou!, símbolo geométrico de etiqueta com letra B e queda integrada, texto exato Baixou!, laranja #FF5C20, palavra branca, flat, sem gradiente/sombra/mockup/texto adicional.
React Bits: componente AnimatedContent oficial com GSAP, usado com deslocamento 8–16px e duração 0,3–0,45s; reduced motion respeitado. Licença e copyright preservados em components/react-bits/LICENSE.md. Origem: https://github.com/DavidHDev/react-bits .
